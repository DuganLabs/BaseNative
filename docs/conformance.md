# Design-system conformance

Every rule here started as a defect found by exploring basenative.com in a
real browser (agent-browser: snapshots, the accessibility tree, bounding
boxes, computed styles, and full-page screenshots, at 320, 393, 768, 1024,
1100, 1280 and 1440px, light and dark). Each defect class becomes a rule,
and each rule is a test at the lowest level that can see it:

- **unit** (`packages/components/src/conformance.test.js`): component and
  token CSS, read as text. The rule lives in the component layer.
- **integration** (`tests/integration/integration.test.js`, "Layout
  conformance"): server-rendered markup. Pages use the shared primitives,
  with no hand spacing.
- **e2e** (`tests/e2e/layout.spec.js`, measured by `tests/e2e/layout-audit.js`):
  geometry that needs a browser. Every route and every `/components/*` page,
  at all seven widths, in both themes.

A rule joins `ENFORCED` in `layout.spec.js` in the same change that fixes
its last violation. Until then, `layoutAudit()` still reports it, so the
sweep stays honest about what is left.

To run the audit by hand against any page, evaluate `layoutAudit` from
`tests/e2e/layout-audit.js` in the page (it is plain browser JS).
